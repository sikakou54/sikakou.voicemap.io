第1条（適用）

  1. 本規約は、本アプリの提供条件及び本アプリの利用に関する当社とユーザーとの間の権利義務関係を定めることを目的とし、ユーザーと当社との間の本アプリの利用に関わる一切の関係に適用されます。
  2. ユーザーは、本アプリのダウンロード及びインストールによって本規約に同意したものとみなされます。
  3. 未成年者が本アプリを利用する場合は、法定代理人（保護者）の同意を得た上でご利用ください。未成年者が本アプリを利用した場合、法定代理人の同意を得ているものとみなします。

第2条（定義）

本規約において使用する以下の用語は、各々以下に定める意味を有するものとします。

  1. 「当社」とは、本アプリの提供者をいいます。
  2. 「ユーザー」とは、本アプリを利用する全ての方をいいます。
  3. 「コンテンツ」とは、ユーザーが本アプリを通じて作成したマインドマップ、音声データ、テキストデータ等の情報をいいます。
  4. 「未成年者」とは、18歳未満の方をいいます。

第3条（本アプリの提供）

  1. 本アプリは、ユーザーに対して、音声入力によるマインドマップ作成機能を提供します。
  2. 本アプリの音声認識機能は端末内で処理されます。
  3. 音声認識機能の利用には、1日あたりの利用回数制限があります。この制限に達した場合、翌日まで一部機能が利用できなくなる場合があります。
  4. 当社は、本アプリの内容を、ユーザーへの事前の通知なく変更することができるものとします。
  5. 当社は、本アプリの提供を、いつでも任意の理由により、一時的または恒久的に中止することができるものとします。
  6. 当社が本アプリのサービスを終了する場合、合理的な期間（原則として30日以上）をもって事前にアプリ内または当社ウェブサイトで告知します。

第4条（広告表示）

  1. 本アプリは、ユーザーに対して、Google AdMobを通じた広告を表示します。
  2. 本アプリは、以下の広告を表示します：
    • バナー広告：ホーム画面に表示
    • インターステーシャル広告（全画面広告）：マップ詳細画面への遷移時に表示
  3. 本アプリで表示される広告は、パーソナライズされていない広告です。ただし、AdMobは、広告配信のために、端末情報、広告インタラクション、IPアドレス等の情報を収集する場合があります。詳細はGoogleのプライバシーポリシーをご確認ください。
  4. ユーザーは、広告の表示を妨げる行為、広告の内容を改ざんする行為、その他広告配信に支障をきたす行為をしてはなりません。
  5. 当社は、広告の内容、品質、正確性について保証しません。広告経由で発生したトラブルについて、当社は責任を負いません。

第5条（有料サービス・サブスクリプション）

5.1 有料サービスの種類

本アプリでは、以下の有料サービスを提供しています：

  1. プレミアムプラン（サブスクリプション）: 月額または年額の定期購読サービス。以下の特典が含まれます：
    • 広告の非表示
    • 音声認識機能の無制限利用
  2. 音声認識時間の追加購入（都度課金）: 音声認識機能の利用時間を追加購入できます。購入した時間は累積され、使い切るまで有効です。

5.2 サブスクリプションの自動更新

プレミアムプランは自動更新サブスクリプションです：

  • サブスクリプション期間終了の24時間以上前に解約しない限り、自動的に更新されます。
  • 更新時に、登録されたお支払い方法に対して料金が請求されます。
  • 無料トライアル期間がある場合、未使用部分は購入時に失効します。

5.3 解約方法

サブスクリプションの解約は、以下の方法で行うことができます：

設定アプリ → Apple ID → サブスクリプション → VoiceMap → サブスクリプションをキャンセル

解約後も、現在の請求期間が終了するまでサービスをご利用いただけます。

5.4 決済処理

すべての決済処理は、Apple Inc.（App Store）を通じて行われます。当社は、クレジットカード情報その他の決済情報を直接収集または保存することはありません。

5.5 返金ポリシー

返金については、Apple Inc.の返金ポリシーに従います：

  • Appleサポート - 返金をリクエストする

5.6 価格変更

当社は、有料サービスの価格を変更する権利を有します。価格変更がある場合は、事前にアプリ内またはメールでお知らせします。変更後の価格は、次回の更新時から適用されます。

第6条（AIアシスタント機能）

6.1 AIアシスタントの概要

本アプリは、プレミアムプラン加入者向けに、AIアシスタント機能を提供します。AIアシスタントは、チャット形式でユーザーの指示に基づき、マインドマップのノード追加・編集・削除、および構造の改善提案を行います。

6.2 AIアシスタントの利用条件

  • AIアシスタント機能は、プレミアムプラン加入者限定の機能です。
  • AIアシスタントの利用には、インターネット接続が必要です。
  • AIアシスタントの応答生成には、外部のAIサービス（Anthropic Claude）を使用します。
  • 月間の利用には上限（トークン数による制限）があり、上限に達した場合は翌月まで利用が制限されます。

6.3 AIアシスタントへの入力情報

AIアシスタントを利用する際、以下の情報がAIサービスに送信されます：

  • ユーザーが入力したチャットメッセージ
  • 現在のマインドマップの構造情報（ノードのテキスト、親子関係等）

重要: ユーザーは、AIアシスタントに機密情報、個人情報、または第三者の権利を侵害する情報を入力しないでください。

6.4 AIアシスタントの出力について

  • AIアシスタントの応答は、AIによる自動生成であり、正確性、完全性、適切性を保証するものではありません。
  • AIアシスタントが提案する内容は参考情報であり、最終的な判断はユーザーの責任において行ってください。
  • AIアシスタントの応答に基づいて行った行為について、当社は責任を負いません。

6.5 AIアシスタント利用時の禁止事項

ユーザーは、AIアシスタントを以下の目的で利用してはなりません：

  • 違法行為、犯罪行為、またはその助長
  • 他者の権利（著作権、プライバシー権等）を侵害する行為
  • 虚偽情報、詐欺的コンテンツの生成
  • 差別的、攻撃的、または有害なコンテンツの生成
  • AIサービスのセキュリティを回避または悪用する行為
  • 大量の自動リクエストによるサービスへの負荷

第8条（コンテンツの取扱い）

  1. ユーザーが本アプリを通じて作成したコンテンツ（マインドマップ、音声データ、テキストデータ等）の著作権は、ユーザーに帰属します。
  2. 本アプリは、ユーザーのコンテンツを端末内にのみ保存し、当社のサーバーには保存しません。
  3. 音声認識処理は端末内で完結し、音声データが外部サーバーに送信されることはありません。
  4. AIアシスタント機能を利用する場合、ユーザーの入力内容およびマインドマップの構造情報は、AIサービス（Anthropic）に送信されます。ただし、当社はこれらの情報を当社のサーバーに保存することはありません。
  5. ユーザーは、PDF出力機能を使用して、作成したマインドマップをエクスポートできます。
  6. AIアシスタントの出力結果に含まれる情報・アイデア・表現について、第三者の知的財産権を侵害しないようご注意ください。AIアシスタントの出力を利用したことによる知的財産権侵害について、当社は責任を負いません。
